Activity 4: Programming with Sensors

For this activity, I programmed the color/reflectivity sensor to control an output on the robot. I chose to make the hub's LED screen display the letter T when the sensor's reflectivity reading fell below the low-reflectivity limit of 30.

Code:

# Setup: Color/Reflectivity Sensor on port D.
from hub import port, light_matrix
import runloop
import color_sensor

# Change this value to set what counts as low reflectivity.
LOW_REFLECTION_LIMIT = 30

async def main():
    # Keep checking the sensor while the program runs.
    while True:
        # Display T when reflectivity is below the limit.
        if color_sensor.reflection(port.D) < LOW_REFLECTION_LIMIT:
            light_matrix.write("T")
        else:
            # Clear the screen when reflectivity is not low.
            light_matrix.clear()

        # Pause briefly before checking again.
        await runloop.sleep_ms(50)

runloop.run(main())
